# Закрывающий тег

Учебный проект курса «Фронтенд-разработчик» от Яндекс.Практикума  
(спринт 4, блок «Декорирование, подходы и инструменты»).

**[Демо-страница](#)**

## Описание

Адаптивная страница-воспоминание о первых этапах обучения фронтенд-разработке. Восемь карточек рассказывают о пройденных спринтах, трудностях и достижениях. В каждой — изображение с фильтром, короткий лейбл, текст и кнопка лайка с анимированным сердцем.

Оформление выдержано в пиксельной эстетике: акцентный шрифт, чёткие рамки, сетчатый фон и SVG-иконки. При наведении кнопки плавно меняют заливку, а при лайке сердце окрашивается, увеличивается и вспыхивает искрами. Кнопка «Сохранить на память» открывает модальное окно с изображением дискеты.

Проект выполнялся на основе **частичной заготовки** с материалами и скриптом лайков. Основная работа — разметка страницы, адаптивная вёрстка, оформление карточек, CSS-фильтры, переходы и анимации.

## Что было сделано

- Собрана HTML-структура страницы: шапка, основной контент с восемью карточками, кнопка «Сохранить на память» и модальное окно
- Реализована резиновая вёрстка: ширина блоков, размеры текста и отступы плавно меняются через `clamp()`. Для мобильного экрана добавлен медиазапрос
- Локально подключены шрифты Inter и Press Start 2P. Для вариативного Inter задан диапазон начертаний, толщина текста управляется через `font-variation-settings`
- Шрифты, цвета и повторяющиеся значения вынесены в CSS-переменные
- Фон собран из трёх градиентов: два `repeating-linear-gradient()` создают сетку, а линейный градиент под ней — переход от светлого к тёмному. Фон зафиксирован относительно окна браузера
- Поверх изображений размещены лейблы с прозрачностью и режимом смешивания `mix-blend-mode: hard-light`
- Обводка лейблов сделана через `text-stroke` с проверкой поддержки в `@supports`. Для браузеров без поддержки предусмотрен вариант на `text-shadow`
- К изображениям применены разные CSS-фильтры, в том числе сочетание нескольких фильтров
- SVG-иконка дискеты переиспользуется через `symbol` и `use` в кнопке сохранения и модальном окне
- Для кнопок настроены состояния `hover` и `focus-visible`. При наведении псевдоэлемент плавно заполняет кнопку, а режим смешивания `difference` меняет цвет текста и иконки поверх заливки
- SVG-сердце разделено на части: сердцевину, основное тело, контур и искры. Для каждой настроены переходы цвета и задержки
- При лайке сердце последовательно закрашивается, увеличивается и возвращается к исходному размеру, после чего появляются искры. Масштабирование и вспышка реализованы через `@keyframes`
- Модальное окно создано на нативном элементе `dialog`, фон за ним затемняется через `::backdrop`. Кнопка «ОК» закрывает окно
- Подключены фавиконки в форматах ICO, SVG и изображение для устройств iOS

## Технологии

- HTML5: семантическая разметка, элемент `dialog`
- CSS3: адаптивная вёрстка, CSS-переменные, `clamp()`, медиазапросы, градиенты, фильтры, режимы смешивания, псевдоэлементы
- CSS-анимации: `transition`, `transform`, `@keyframes`
- Вариативные шрифты: `@font-face`, `font-variation-settings`
- SVG: встроенная разметка, группировка элементов через `g`, переиспользование иконок через `symbol` и `use`
- JavaScript: скрипт переключения состояния лайка и текста Like / Unlike
- GitHub Pages для публикации сайта

## Чему научился

- Создавать резиновую вёрстку через `clamp()`: плавно менять размеры блоков, текста и отступов без большого количества медиазапросов
- Подключать вариативные шрифты и управлять их насыщенностью через `font-variation-settings`
- Собирать сложный фон из нескольких градиентов и управлять порядком их наложения
- Применять CSS-фильтры и режимы смешивания для оформления изображений, текста и интерактивных элементов
- Работать со структурой SVG: выделять части иконки, объединять их в группы и анимировать независимо друг от друга
- Сочетать переходы и покадровые анимации. Настраивать задержки так, чтобы отдельные движения складывались в последовательный эффект
- Продумывать не только появление эффекта при наведении, но и его плавное исчезновение при уходе курсора
- Использовать `@supports` и запасные варианты оформления для свойств с ограниченной поддержкой
- Создавать модальное окно на элементе `dialog` и оформлять его фон через `::backdrop`
